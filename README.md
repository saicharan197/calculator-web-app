# 🧮 Calculator Web Application

A modern, responsive calculator built using HTML, CSS, and vanilla JavaScript. This project demonstrates DOM manipulation, event handling, input validation, and basic arithmetic operations.

## ✨ Features

* Basic arithmetic operations: addition, subtraction, multiplication, and division.
* Decimal and percentage calculations.
* Positive/negative number toggle.
* Clear and backspace functionality.
* Keyboard input support.
* Calculation history saved using localStorage.
* Dark and light themes.
* Copy-result functionality.
* Error handling for invalid expressions and division by zero.
* Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Event Listeners
* Browser localStorage API

## 🚀 Getting Started

### Prerequisites

A modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/saicharan197/calculator-web-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd calculator-web-app
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.
